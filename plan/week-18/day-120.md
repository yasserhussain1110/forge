# Day 120 · Week 18 · Realistic load testing

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Tasks
- [ ] Download the ShareGPT dataset that vLLM's benchmarks use (the vLLM benchmarks README explains where to get it).
- [ ] Extend your benchmark to replay real conversations with requests arriving at random times (a Poisson process) at a chosen rate.
- [ ] Sweep the request rate upward until latency explodes. Plot p50 and p99 TTFT and TPOT against request rate.
- [ ] Find the maximum request rate where p99 TTFT stays under, say, 1 second. This is your server's "capacity".

## Resources
- [vLLM repository](https://github.com/vllm-project/vllm) (`benchmarks/` folder)

## Done when
You have a latency-versus-load plot and a capacity number.
