# Day 122 · Week 18 · Cancellation and backpressure

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Tasks
- [ ] When a client disconnects, cancel its request inside the engine and free its blocks immediately.
- [ ] Add a maximum queue length. When it's full, return HTTP 429 or 503 instead of accepting work you can't serve in time.
- [ ] Add a per-request timeout.
- [ ] Return clear errors for bad input: prompt too long, invalid parameters.
- [ ] Test each of these behaviours with a script.

## Done when
Under overload the server rejects work cleanly instead of slowing down for everyone.
