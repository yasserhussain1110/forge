# Day 123 · Week 18 · Stress tests

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Tasks
- [ ] Write a randomized stress test: random prompt lengths, output lengths, sampling settings, cancellations and arrival times, running for 30 minutes.
- [ ] Check invariants afterwards: no leaked blocks (all blocks free once idle), every request finished or was cancelled, no crashes.
- [ ] Fix every bug it finds, and add a regression test for each one.
