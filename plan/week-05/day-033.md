# Day 33 · Week 5 · Your first generated text

**Time:** about 3 hours

## Tasks
- [ ] Read the Hugging Face chat templating guide. Use `tokenizer.apply_chat_template` to turn a list of messages into token IDs.
- [ ] Write a greedy generation loop **without any cache**: run the full sequence each step, take the highest-scoring token, append it, repeat.
- [ ] Stop when the model emits an end-of-sequence token. Find the right IDs in `generation_config.json`; Llama 3 has more than one.
- [ ] Compare your output with Hugging Face's greedy output for the same prompt. They should be identical in float32.
- [ ] Ask your engine a question and paste the answer in `notes/day-033.md`. This is a milestone.
