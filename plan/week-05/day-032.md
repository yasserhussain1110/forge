# Day 32 · Week 5 · The full model with real weights

**Time:** about 3 hours

## Tasks
- [ ] Assemble the decoder layer and the full model: embedding, N decoder layers, final norm, output projection (`lm_head`).
- [ ] Name your modules so their parameter names match the checkpoint exactly; then loading is just `load_state_dict`.
- [ ] Handle tied embeddings: Llama 3.2 1B reuses the embedding matrix as `lm_head` (look for `tie_word_embeddings` in the config).
- [ ] Load the real weights, run a prompt through both your model and Hugging Face's, and compare the output logits. Record the maximum difference.

## Resources
- [PyTorch: Saving and loading models](https://pytorch.org/tutorials/beginner/saving_loading_models.html)

## Done when
Your logits match Hugging Face's closely (in float32, a maximum difference around 1e-4 or smaller), and the top predicted token is the same.
