# Day 29 · Week 5 · Set up the Forge repo and inspect a real model

**Time:** about 3 hours

## Why today matters
From today you're building Forge, your own inference engine. First, look at what a real model checkpoint contains.

## Tasks
- [ ] Set up your environment on your own machine (your RTX 4060's 8 GB is plenty for Llama 3.2 1B), with `torch` (CUDA build), `transformers`, `safetensors` and `huggingface_hub`.
- [ ] Llama 3.2 is gated: accept Meta's license on the model's Hugging Face page, then log in with the Hugging Face command-line tool.
- [ ] In the `forge` repo, create the package layout you want (for example `forge/` for code, `tests/`, `benchmarks/`, `notes/`). Decide it yourself and write the reasoning in `notes/day-029.md`.
- [ ] Generate text with Llama 3.2 1B Instruct using Hugging Face's own `transformers` code. This is your reference for correctness.
- [ ] Download the model files and open `config.json`. Write down every field and what it means.
- [ ] Open the `.safetensors` file with the `safetensors` library and list every tensor name, shape and dtype.

## Resources
- [safetensors docs](https://huggingface.co/docs/safetensors)
- [huggingface_hub: downloading files](https://huggingface.co/docs/huggingface_hub/guides/download)

## Done when
You have a list of every weight in the model with its shape, and you know which config field explains each shape.
