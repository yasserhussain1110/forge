# Day 30 · Week 5 · RMSNorm and MLP, tested against Hugging Face

**Time:** about 3 hours

## Why today matters
The professional way to build a model is piece by piece, testing each piece against a trusted reference. Start the habit now.

## Tasks
- [ ] Write your own RMSNorm module.
- [ ] Write your own MLP (SwiGLU feed-forward) module.
- [ ] Install `pytest`. For each module, write a test that copies weights from Hugging Face's `LlamaRMSNorm` and `LlamaMLP` into yours, runs the same random input through both, and checks the outputs match with `torch.testing.assert_close`.
- [ ] Run tests in float32 first. Note what happens to the tolerance in bfloat16.
