# Day 31 · Week 5 · RoPE and attention with GQA

**Time:** about 3 hours

## Why today matters
Attention is where most bugs hide. Testing it in isolation saves days of debugging later.

## Tasks
- [ ] Write a function that computes RoPE frequencies from the config (`rope_theta`, head dimension).
- [ ] Check `config.json` for a `rope_scaling` section. Llama 3.1 and 3.2 use a "llama3" scaling rule; read how Hugging Face computes it (search for `_compute_llama3_parameters` in `transformers`) and implement it.
- [ ] Write your attention module: query, key and value projections, RoPE, GQA (repeat each KV head for its group of query heads), causal mask, output projection.
- [ ] Test it against Hugging Face's `LlamaAttention` with copied weights.
