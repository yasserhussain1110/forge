# Day 151 · Week 22 · Prototype disaggregation

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Tasks
- [ ] On your own GPU, run one prefill worker process and one decode worker process (Llama 3.2 1B is small enough for two copies). Don't rent for this stretch week.
- [ ] After prefill, send the request's KV blocks from the prefill worker to the decode worker with `gloo` point-to-point send and receive. Keep the transfer code behind one function so it could switch to NCCL between real GPUs.
- [ ] The decode worker allocates blocks, receives the KV data, and continues generation.
- [ ] Test: output must match the normal engine.

## Resources
- [torch.distributed send and recv](https://pytorch.org/docs/stable/distributed.html)

## Done when
One request flows correctly through both workers.
