# Day 109 · Week 16 · Packed prefill without padding

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Why today matters
Padding prompts to the same length wastes compute. Production engines concatenate all prompts into one long sequence and tell the attention kernel where each one starts.

## Tasks
- [ ] Read the variable-length interface of the `flash-attn` library (`flash_attn_varlen_func`) and its `cu_seqlens` argument (cumulative sequence lengths).
- [ ] Change prefill to pack several prompts into one sequence with no padding. Positions for RoPE restart at 0 for each prompt.
- [ ] Update your prefill attention kernel (day 82), or use `flash-attn`, so that tokens only attend within their own prompt.
- [ ] Test that packed prefill gives the same results as prefilling each prompt alone.
