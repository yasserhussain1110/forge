# Day 108 · Week 16 · Preemption, implemented

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Tasks
- [ ] Implement preemption by recompute: free the victim's blocks and put it back in the waiting queue with its prompt plus the tokens generated so far.
- [ ] When it is readmitted, prefill everything and continue. With greedy sampling its final output must match an uninterrupted run.
- [ ] Stress test: give the engine a deliberately tiny cache and many long requests. Nothing should crash or hang, and every request should finish.

## Done when
The stress test passes with a tiny cache.
