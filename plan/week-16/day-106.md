# Day 106 · Week 16 · Integrate the paged cache

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Tasks
- [ ] Replace the slot-based cache with the paged cache in the engine.
- [ ] The scheduler now admits requests based on free blocks rather than free slots.
- [ ] Decide how many blocks to allocate at startup: measure free GPU memory after loading the model, keep a safety margin, and give the rest to the cache. Print the result at startup.
- [ ] Run all correctness tests: outputs must match the unpaged engine exactly with greedy sampling.

## Done when
The engine runs on the paged cache and all tests pass.
