# Day 164 · Week 24 · Open-source pull request, part 1

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Tasks
- [ ] Reproduce the issue, or write a failing test that shows it.
- [ ] Read the surrounding code until you understand how it fits in. Compare it with how you solved the same problem in Forge.
- [ ] Implement the fix or feature, following the project's style.

## Done when
Your change works locally with a test.
