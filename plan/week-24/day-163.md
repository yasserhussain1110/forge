# Day 163 · Week 24 · Pick an open-source issue

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Why today matters
A merged contribution to vLLM, SGLang, PyTorch or Triton is proof that you can work in a large real codebase, and maintainers of these projects often work at the companies you want to join.

## Tasks
- [ ] Read the contributing guides of vLLM and SGLang.
- [ ] Browse issues labelled "good first issue" or "help wanted". Prefer something in an area you now know well: scheduling, prefix caching, kernels, benchmarks or quantization.
- [ ] Pick one or two, comment on the issue to say you're working on it, and set up the project's development environment.
- [ ] Run the project's test suite locally.

## Resources
- [vLLM contributing guide](https://docs.vllm.ai/en/latest/contributing/)
- [vLLM issues](https://github.com/vllm-project/vllm/issues)
- [SGLang issues](https://github.com/sgl-project/sglang/issues)

## Done when
You've claimed an issue and the project's tests run on your machine.
