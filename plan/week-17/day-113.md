# Day 113 · Week 17 · RadixAttention

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Why today matters
Many requests share the same beginning: a long system prompt, the earlier turns of a chat, or few-shot examples. If you keep their KV cache around, you can skip most of the prefill for the next request.

## Tasks
- [ ] Read the SGLang paper, focusing on the RadixAttention section.
- [ ] Understand the radix tree: each path from the root is a token sequence, and each node points to cached KV blocks.
- [ ] Understand eviction: least-recently-used leaves are freed first when memory runs out.
- [ ] Draw a radix tree on paper for 4 chat requests that share a system prompt.
