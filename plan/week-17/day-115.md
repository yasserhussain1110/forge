# Day 115 · Week 17 · Implement prefix caching

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Tasks
- [ ] Add reference counts to blocks: a block is only freed when no running sequence uses it.
- [ ] When a request arrives, find the longest cached prefix, reuse those blocks, and only prefill the remaining tokens.
- [ ] Keep freed-but-cached blocks in a least-recently-used list, and evict from it only when the allocator runs out.
- [ ] Test: outputs with prefix caching must equal outputs without it. Also test eviction under memory pressure.

## Done when
Tests pass with prefix caching on, including under memory pressure.
