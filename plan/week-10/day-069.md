# Day 69 · Week 10 · Your first CUDA kernels

**Time:** about 3 hours

## Tasks
- [ ] Write a vector-add kernel in CUDA, check it against PyTorch, and measure its memory bandwidth (bytes moved ÷ time). Compare with the GPU's peak bandwidth.
- [ ] Write a naive matrix-multiply kernel (one thread per output element) and measure its FLOPs per second against `torch.matmul`.
- [ ] Write a tiled version using shared memory (from day 66) and measure again.
- [ ] Record all three in your notes. Don't worry if your matmul is far slower than PyTorch's; the point is to see why.
