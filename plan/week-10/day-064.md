# Day 64 · Week 10 · GPU vocabulary

**Time:** about 2.5 hours

## Why today matters
To make inference faster you need a mental model of the hardware. This month you go one level below PyTorch.

## Tasks
- [ ] Read the Modal GPU Glossary. Focus on: streaming multiprocessor (SM), CUDA core, tensor core, warp, thread block, high-bandwidth memory (HBM), shared memory and L2 cache.
- [ ] Draw your GPU's layout on paper: how many SMs it has, how big its memory and caches are. Look up the numbers on the GPU's datasheet.
- [ ] Note the speed gap: on-chip memory is roughly 10× faster than HBM. Most kernel optimization is about using the fast memory well.
