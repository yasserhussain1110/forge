# Day 25 · Week 4 · Grouped-query attention and KV memory

**Time:** about 2.5 hours

## Why today matters
During generation, the engine stores every token's keys and values (the KV cache). Its size limits how many users you can serve. Grouped-query attention (GQA) shrinks it.

## Tasks
- [ ] Read the multi-query attention (MQA) paper's introduction.
- [ ] Read the GQA paper's introduction and method.
- [ ] Calculate by hand, for Llama 3 8B (32 layers, 32 query heads, 8 KV heads, head dimension 128, 16-bit values = 2 bytes):
  - KV cache bytes per token: 2 (K and V) × layers × KV heads × head dim × 2 bytes.
  - KV cache size for one 8,000-token conversation.
  - The same numbers if it had 32 KV heads (no GQA).
