# Day 23 · Week 4 · Rotary position embeddings (RoPE)

**Time:** about 3 hours

## Why today matters
Llama tells the model where each token is by rotating query and key vectors. You'll implement this in week 5, and getting it slightly wrong produces garbage output.

## Tasks
- [ ] Read the EleutherAI blog post on rotary embeddings.
- [ ] Skim the RoFormer paper, focusing on the figures and the 2-D rotation example.
- [ ] Implement a 2-D rotation of a vector by angle θ in PyTorch, and verify that the dot product of two rotated vectors depends only on the **difference** of their angles. This is the key property of RoPE.
- [ ] Note that Hugging Face's Llama code uses the "rotate half" layout; look at the `rotate_half` function in `modeling_llama.py`.
