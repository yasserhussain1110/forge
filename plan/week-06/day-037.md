# Day 37 · Week 6 · Implement the KV cache

**Time:** about 3 hours

## Why today matters
The KV cache is the first and most important inference optimization. Instead of recomputing keys and values for every earlier token at every step, you store them.

## Tasks
- [ ] Design a cache object: for each layer, a preallocated key tensor and value tensor of shape [batch, KV heads, max sequence length, head dimension].
- [ ] Change attention to: compute K and V only for the new tokens, write them into the cache at the right position, then attend over everything cached so far.
- [ ] Split generation into prefill (whole prompt, with causal mask) and decode (one token, no mask needed).
- [ ] Make sure RoPE uses the correct **absolute position** for the new token during decode, not position 0. This is the most common KV cache bug.
