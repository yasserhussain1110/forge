# Day 40 · Week 6 · Stop conditions and streaming text

**Time:** about 3 hours

## Tasks
- [ ] Support `max_tokens`, multiple end-of-sequence token IDs, and a maximum context length (refuse prompts that are too long).
- [ ] Return a finish reason with each result: `stop` (hit end-of-sequence) or `length` (hit a limit). The OpenAI API reports this too.
- [ ] Build an incremental detokenizer that turns a stream of token IDs into text pieces. Remember day 20: don't emit half an emoji. (Hint: if the decoded text ends with the Unicode replacement character `\ufffd`, wait for the next token.)
- [ ] Test with prompts that make the model write emoji and non-English text.
