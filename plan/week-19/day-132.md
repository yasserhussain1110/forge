# Day 132 · Week 19 · Medusa, EAGLE and prompt lookup

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Tasks
- [ ] Read the Medusa paper's introduction and method: extra prediction heads instead of a separate draft model.
- [ ] Read the EAGLE paper's introduction and method: drafting from the target model's own hidden states. Note why it gets higher acceptance rates.
- [ ] Implement prompt-lookup (n-gram) drafting: guess the next tokens by finding the last few generated tokens earlier in the prompt. It needs no draft model at all.
- [ ] Measure it on a summarization or code-editing workload, where output often copies the input.
