# Day 130 · Week 19 · Speculative sampling with rejection

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Tasks
- [ ] Implement the accept/reject rule from day 128 so speculative decoding works with temperature above 0.
- [ ] Write a statistical test: for a fixed short prompt, sample the next few tokens thousands of times with and without speculation, and check the distributions match (a chi-squared test works).
- [ ] Make it work inside continuous batching, where each sequence may accept a different number of tokens per step. Keep it simple: a fixed k for everyone.
