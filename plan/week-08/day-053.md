# Day 53 · Week 8 · A benchmark harness

**Time:** about 3 hours

## Tasks
- [ ] Look at the serving benchmark script in the vLLM repository (in the `benchmarks/` folder) to see how they measure.
- [ ] Write your own benchmark client: send N requests with K of them in flight at once, stream each, and record TTFT, TPOT and end-to-end latency per request.
- [ ] Report the median, p90 and p99 of each metric, plus total output tokens per second.
- [ ] Save results as JSON so you can compare runs later.
- [ ] Run it against your server with 1, 4 and 16 concurrent requests.
