# Day 50 · Week 8 · FastAPI and async Python

**Time:** about 3 hours

## Why today matters
An engine is only useful behind an API. The industry standard is the OpenAI-compatible HTTP API, so that existing clients work with your server unchanged.

## Tasks
- [ ] Do the FastAPI tutorial up to and including "Request Body".
- [ ] Read the Python asyncio introduction: what `async`, `await` and the event loop are.
- [ ] Understand the key problem: model computation is blocking, so running it directly inside an async handler freezes the whole server. Read about `asyncio.to_thread` and `run_in_executor`.
- [ ] Write a toy FastAPI server with an endpoint that sleeps for 2 seconds in a thread, and confirm another request still gets answered meanwhile.
