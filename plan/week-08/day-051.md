# Day 51 · Week 8 · The chat completions endpoint

**Time:** about 3 hours

## Tasks
- [ ] Read the OpenAI API reference for chat completions: request fields and response format.
- [ ] Implement `POST /v1/chat/completions` (no streaming yet) supporting `messages`, `max_tokens`, `temperature`, `top_p` and `seed`. Return `usage` (prompt and completion token counts) and `finish_reason`.
- [ ] Add `GET /v1/models`.
- [ ] Test it with the official `openai` Python client pointed at your server (`base_url="http://localhost:8000/v1"`).
- [ ] Since the engine handles one request at a time for now, guard it with a lock.
- [ ] Accept the W3C `traceparent` header. Its format is `00-<32-hex trace id>-<16-hex parent span id>-<2-hex flags>`. If present and valid, put its trace ID in the request's log line; if missing or malformed, generate a new trace ID and carry on (never reject the request). Test it with `curl -H "traceparent: 00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01" ...`. Later (12-month plan, W43), the gateway sends this header and Forge adds its own spans under that trace.
