# Day 138 · Week 20 · A 4-bit matrix multiply kernel

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Tasks
- [ ] Load the AWQ checkpoint into Forge.
- [ ] Write a Triton matrix multiply that unpacks 4-bit weights, applies scales and zero points per group, and multiplies with 16-bit activations ("W4A16"). Start from your day-73 matmul.
- [ ] Test it against dequantizing in PyTorch and doing a normal matmul.
- [ ] Measure decode speed for Llama 3.2 3B in 16-bit versus 4-bit, and compare with your day-45 style theoretical limit for each. Keep the 16-bit run's context short so its KV cache fits next to the weights.

## Done when
4-bit decode works and is measurably faster.
