# Day 136 · Week 20 · 8-bit weight-only quantization

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Tasks
- [ ] Implement 8-bit weight-only quantization with one scale per output channel, applied when the model loads.
- [ ] Write a matrix multiply that converts the 8-bit weights to 16 bits on the fly. Start with plain PyTorch, then a Triton kernel that does it inside the matmul (look at how gpt-fast does its int8 path).
- [ ] Measure perplexity (how surprised the model is by real text; lower is better) on WikiText-2 before and after, and decode speed before and after.

## Resources
- [Hugging Face: Perplexity of fixed-length models](https://huggingface.co/docs/transformers/perplexity)
- [gpt-fast repository](https://github.com/pytorch-labs/gpt-fast) (`quantize.py`)

## Done when
You have perplexity and speed numbers for 16-bit versus 8-bit.
