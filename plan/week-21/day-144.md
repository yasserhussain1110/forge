# Day 144 · Week 21 · Shard attention and the MLP

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Tasks
- [ ] Following your day-141 diagrams, make each process load only its share of each weight matrix.
- [ ] Split attention by heads (each GPU gets some query heads and the matching KV heads), and split the MLP by columns then rows.
- [ ] Add the all-reduces in the right places.
- [ ] Each GPU keeps a KV cache only for its own heads; adjust the block allocator so all GPUs make the same decisions.
- [ ] Test locally: run Llama 3.2 1B as two processes on your one GPU with the `gloo` backend. It's slow, but output must match the single-GPU engine, and that checks your sharding for free.

## Done when
Two-process output matches single-GPU output on your own machine.
