# Day 145 · Week 21 · Llama 3.1 8B on two GPUs

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Why today matters
This is the plan's one required rental: tensor parallelism can't be measured on one GPU. Keep the session short by doing all preparation locally first.

## Tasks
- [ ] Before renting: make sure the day-143 benchmark and day-144 test run locally, download nothing you won't use, and write the exact list of commands for the session in `scripts/rental-session/`.
- [ ] Rent a machine with two 24 GB GPUs (2× L4 or similar; PCIe is fine, NVLink isn't needed). Llama 3.1 8B in 16-bit (about 16 GB) fits on one of them.
- [ ] In the session, in this order:
  - [ ] Run the day-143 all-reduce benchmark with NCCL and compare with the bandwidth you looked up on day 142.
  - [ ] Rerun the day-144 test with NCCL: two-GPU output must match single-GPU output.
  - [ ] Make CUDA graphs work with the all-reduces in place (NCCL operations can be captured).
  - [ ] Run Llama 3.1 8B on one GPU and on two GPUs; measure decode speed at batch size 1 and throughput under load.
  - [ ] Capture an Nsight Systems trace on both GPUs for day 146.
- [ ] Copy all results and traces to your machine, then shut the rented machine down.
- [ ] Compare with your day-142 prediction.

## Done when
`RESULTS.md` has one-GPU versus two-GPU numbers for the 8B model, and the rented machine is shut down.
