# Day 1 · Week 1 · Set up and meet tensors

**Time:** about 2.5 hours

## Why today matters
Everything in an inference engine is a tensor (a multi-dimensional array) moving through a GPU. Today you get a working environment and learn what tensors are.

## Tasks
- [ ] Install Python 3.11+ and create a virtual environment (`python -m venv .venv`) in a scratch folder.
- [ ] Install PyTorch (pick the command for your machine on the PyTorch "Get Started" page) and Jupyter.
- [ ] Create a GitHub repo named `forge` with a `notes/` folder. You'll commit notes and exercises here every day.
- [ ] Work through the **Tensors** section of PyTorch "Learn the Basics", typing every example yourself.
- [ ] In `notes/day-001.md`, write down: what is a tensor, what are `shape`, `dtype` and `device`.

## Resources
- [PyTorch: Get Started](https://pytorch.org/get-started/locally/)
- [PyTorch: Learn the Basics, Tensors](https://pytorch.org/tutorials/beginner/basics/tensorqs_tutorial.html)

## Done when
You can create tensors, change their shape and move them between CPU and GPU (or know how you would), and your notes are committed.
