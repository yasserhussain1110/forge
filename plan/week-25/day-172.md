# Day 172 · Week 25 · Design batch inference on Spark

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Why today matters
Not all inference is chat. Companies run LLMs over billions of rows of data offline, for example to classify or summarize documents. This is especially relevant for Databricks.

## Tasks
- [ ] Read the Databricks documentation on batch inference with LLMs (search for "AI Functions" and "ai_query").
- [ ] Learn the basics of Spark's execution model if you haven't: jobs, stages, tasks, partitions.
- [ ] Practice with a 45-minute timer: "Design a system that runs an LLM over a 1-billion-row table as cheaply as possible."
- [ ] Cover: throughput over latency, very large batches, sorting by length, prefix caching for shared instructions, retries, checkpointing progress, and cost estimates using your own numbers.
- [ ] Write up your design.

## Resources
- [Databricks documentation](https://docs.databricks.com/) (search "ai_query" and "batch inference")
- [Spark cluster mode overview](https://spark.apache.org/docs/latest/cluster-overview.html)
