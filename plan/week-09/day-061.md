# Day 61 · Week 9 · Continuous integration

**Time:** about 2.5 hours

## Why today matters
From now on you'll make risky performance changes. Automatic tests on every push catch the moment something silently breaks correctness.

## Tasks
- [ ] Make your correctness tests runnable on CPU with a tiny, randomly initialized Llama (for example 2 layers, hidden size 64), so they don't need a GPU or a download. Hugging Face's `LlamaConfig` and `LlamaForCausalLM` can create it as the reference.
- [ ] Do the GitHub Actions quickstart.
- [ ] Add a workflow that installs your package and runs `pytest` on every push and pull request.
- [ ] Add a linter (`ruff`) to the workflow.
- [ ] Add a status badge to your README.

## Resources
- [GitHub Actions quickstart](https://docs.github.com/en/actions/writing-workflows/quickstart)
- [Ruff](https://docs.astral.sh/ruff/)

## Done when
Pushing a commit triggers a green test run on GitHub.
