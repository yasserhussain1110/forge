# Day 78 · Week 12 · Online softmax

**Time:** about 2.5 hours

## Why today matters
FlashAttention is built on one trick: computing softmax in a single pass over data that arrives in chunks. Understand this and the rest follows.

## Tasks
- [ ] Read "Online normalizer calculation for softmax" (Milakov and Gimelshein). It's short.
- [ ] Derive the online update on paper: keep a running maximum and a running sum, and rescale the sum whenever the maximum changes.
- [ ] Implement it in plain PyTorch over chunks of a vector and check it matches `torch.softmax`.
- [ ] Extend it to compute softmax(x) · v in one pass (rescaling the running output too). This is FlashAttention in miniature.

## Resources
- [Online normalizer calculation for softmax](https://arxiv.org/abs/1805.02867)

## Done when
Your one-pass softmax-times-values matches the two-pass result.
