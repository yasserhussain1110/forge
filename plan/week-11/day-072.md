# Day 72 · Week 11 · Triton: fused softmax

**Time:** about 3 hours

## Why today matters
"Fusion" means doing several operations in one kernel so the data is read from memory once instead of several times. It's the main trick for speeding up memory-bound work like decode.

## Tasks
- [ ] Do Triton tutorial 02, "Fused Softmax".
- [ ] Count how many times PyTorch's unfused softmax reads and writes the data, versus the fused kernel.
- [ ] Run the benchmark and explain the speed-up using that count.
