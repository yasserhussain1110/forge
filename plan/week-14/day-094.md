# Day 94 · Week 14 · Static batching

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Tasks
- [ ] Extend the engine to generate for several prompts at once: pad prompts to the same length, and use an attention mask that ignores padding.
- [ ] Make sure RoPE positions are correct for each sequence despite padding (left padding versus right padding matters here; write down which you chose and why).
- [ ] Test that each sequence's output equals what it produces alone.
- [ ] Measure total tokens per second at batch sizes 1, 4, 16 and 64. Plot it.

## Done when
Batched outputs match single outputs, and your throughput plot shows the gain.
