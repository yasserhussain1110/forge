# Day 95 · Week 14 · Design doc 2

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Tasks
- [ ] Before building the scheduler, design it. Write `docs/design/002-scheduler.md` covering:
  - The request lifecycle: waiting, running, finished, cancelled.
  - What happens in one engine step: which requests to add, which to prefill, which to decode.
  - How the web server talks to the engine (a queue in one process? separate processes?).
  - What limits how many requests can run at once (KV cache memory).
  - Alternatives you considered and why you rejected them.
- [ ] Draw a diagram of the components and the request flow.
- [ ] Read how nano-vllm structures its engine (`engine/` folder) for comparison, after writing your draft.
