# Day 97 · Week 14 · Continuous batching

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Tasks
- [ ] Give the KV cache a fixed number of "slots", one per running request.
- [ ] Each engine step: admit waiting requests into free slots and prefill them, then run one decode step for all running requests together, then free the slots of finished requests.
- [ ] Your decode attention kernel from day 85 already supports different lengths per sequence; use it here.
- [ ] Test that every request's output matches running it alone (with greedy sampling).
- [ ] Run your day-53 benchmark at 16 and 64 concurrent requests and compare with day 54.

## Done when
Throughput at 16+ concurrent requests is many times higher than before.
