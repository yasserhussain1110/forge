# Day 102 · Week 15 · Block allocator and block tables

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Tasks
- [ ] Implement a block allocator: a pool of free physical block IDs, with allocate and free.
- [ ] Implement per-sequence block tables that grow by one block whenever a sequence fills its last block.
- [ ] Add a check the scheduler can call: "are there enough free blocks to admit this request?"
- [ ] Write unit tests, including: allocating everything then freeing everything, running out of blocks, and many sequences growing at once. This part runs on CPU and is easy to test thoroughly.

## Done when
Your allocator tests pass.
