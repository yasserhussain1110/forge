# Day 103 · Week 15 · Writing keys and values into blocks

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Tasks
- [ ] Change the KV cache storage to one big tensor per layer of shape [number of blocks, block size, KV heads, head dimension] (or another layout; write down why you chose it).
- [ ] For each new token, compute its "slot": physical block × block size + offset within the block.
- [ ] Write new keys and values into their slots, either with a small Triton kernel or with PyTorch indexing (`index_copy_`).
- [ ] Test by writing known values and reading them back through the block table.

## Done when
Write-then-read tests pass for many sequences at once.
