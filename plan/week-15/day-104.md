# Day 104 · Week 15 · Paged decode attention kernel

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Tasks
- [ ] Modify your day-85 decode attention kernel to find each key and value block through the block table instead of a contiguous range.
- [ ] Test it against a reference: gather each sequence's blocks into a contiguous tensor with PyTorch, run normal attention, and compare.
- [ ] Benchmark it against your contiguous decode kernel. The paged version should cost only a little more.

## Resources
- How vLLM does it: look at the `attention/` and `v1/attention/` folders in the [vLLM repository](https://github.com/vllm-project/vllm).

## Done when
The paged kernel passes tests and its overhead is measured.
