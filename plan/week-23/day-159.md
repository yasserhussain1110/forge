# Day 159 · Week 23 · The README

**Time:** about 3 hours (plus 30 minutes of coding practice)

## Why today matters
Most hiring managers will spend 2 minutes on your repo. The README must tell them what you built, how good it is, and how deep you went.

## Tasks
- [ ] Write the top section: one sentence on what Forge is, the journey chart, and the headline comparison with vLLM.
- [ ] Add an architecture diagram showing the server, scheduler, block manager, model runner and kernels.
- [ ] Add a feature list, each item linking to its design doc or blog post.
- [ ] Add a quickstart that a stranger can follow in 5 minutes. Test it on a fresh machine.
- [ ] Look at the READMEs of vLLM, SGLang and nano-vllm for structure ideas.

## Done when
A friend can understand the project from the README alone.
