The config.json for Llama-3.2-1B

1. architectures -> LlamaForCasualLM
2. attention_bias -> extra bias after multiplication
3. attention_dropout -> this is used to drop a fraction of items randomly
4. bos_token_id -> beginning of sequence token number
5. eos_token_id -> end of sequence token number
6. head_dim -> width of single attention head
7. hidden_act -> activation function in the feed forward block, in the case of llama its silu = x * sigmoid
8. hidden_size -> width of the vector
9. initializer_range -> standard deviation used to randomly fill weights
10. intermediate_size -> width of the feed forward block. in our case its - 8192
